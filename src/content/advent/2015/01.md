## Notes

Part one folds each instruction into a running floor. Part two uses `scan` so
the first matching position is returned without storing every intermediate value.

## Solution

```rust
fn part1(input: &str) -> i32 {
    input.chars().fold(0, |floor, instruction| match instruction {
        '(' => floor + 1,
        ')' => floor - 1,
        _ => floor,
    })
}

fn part2(input: &str) -> usize {
    input
        .chars()
        .scan(0, |floor, instruction| {
            *floor += if instruction == '(' { 1 } else { -1 };
            Some(*floor)
        })
        .position(|floor| floor == -1)
        .unwrap()
        + 1
}
```
